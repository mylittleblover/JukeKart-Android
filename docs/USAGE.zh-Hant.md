# JukeKart Beta 使用說明

[简体中文](USAGE.md) | **繁體中文** | [English](USAGE.en.md) | [日本語](USAGE.ja.md)

## 安裝與匯入音樂

1. 在 Android 8.0 或更高版本上安裝 JukeKart `0.1.0-beta04` Release APK。系統可能會要求授權安裝未知應用程式來源。
2. 下載完整 [`.mkwpack` 資源包（MEGA）](https://mega.nz/file/j1BxBRyI#cJxJEof3uY3JxDSPiIep7WOI1mNyI2h3Vz7yZ3YRdOc)（或自備相容的 `.mkwpack`），並儲存於系統檔案選擇器可存取的位置。應用程式會將曲包內容匯入內部儲存空間，請預留足夠容量。曲包結構詳見[格式說明](PACK-FORMAT.zh-Hant.md)。
3. 首次啟動可在歡迎頁授予通知權限並直接選擇匯入 `.mkwpack`，也可隨時開啟 **設定 → 匯入 .mkwpack** 選取檔案並等待校驗。完成後可在 **匯入詳情** 查看可播放曲目。可陸續匯入多個曲包，內容會自動合併至曲庫。
4. 若匯入中斷，可在設定中選擇 **繼續匯入**。若系統檔案存取授權已過期，請依提示重新選取同一個曲包。

若手機曾安裝過以舊測試憑證簽署的 Alpha 版本，同套件名稱的 Release APK 將無法直接覆蓋安裝。請先匯出應用程式內備份並保留原始曲包，再解除安裝舊版；解除安裝會清除應用程式內部檔案。

## 播放與編輯

| 功能 | 操作 |
|---|---|
| 賽道控制台 | 從探索頁選擇已有音訊的賽道。控制台會顯示該賽道可用的階段、尾奏、最後一圈與音樂版本控制。 |
| 組曲與路線 | 在賽道或地圖頁面選擇組曲或路線。可縮放、拖曳地圖，並從賽道標記開啟預覽。可用的路段音樂取決於曲包內容。 |
| 自訂路線 | 在路線清單中建立路線，依序加入賽道與可用路段，完成後儲存或播放。 |
| 流程編排器 | 在支援的賽道上開啟流程編排器，選擇階段與播放方式，儲存預設或匯出流程 JSON。 |
| 點唱機與播放清單 | 搜尋曲目、加入最愛，或將曲目加入播放清單。播放頁提供佇列與播放順序控制。 |
| 背景控制 | 開始播放後可離開應用程式，使用系統媒體控制項、桌面小工具或快速設定資訊方塊。Android 13 及以上可依提示授予通知權限。 |

賽道封面、地圖與解鎖演出影片可隨曲包提供。缺少這些檔案時，應用程式會顯示內建的封面、地圖或橫向動畫。缺少的音訊則須透過包含對應資源的曲包補齊。

## 備份與還原

開啟 **設定 → 資料備份與匯出**，將備份儲存至應用程式外部。還原時可選擇 **合併至目前資料** 或 **完整覆蓋還原**。覆蓋還原會以備份中的播放清單、收藏、預設、路線、播放統計與設定取代目前資料；音訊檔案仍須透過原始 `.mkwpack` 重新匯入。亦可單獨匯出 M3U 播放清單。

## 回報問題

回報播放、匯入或顯示問題時，請註明 JukeKart 版本、裝置型號、Android 版本、曲名或曲包版本以及重現步驟。若問題發生於背景播放，也請說明當時使用的是通知、快速設定資訊方塊還是桌面小工具。[提交 GitHub Issue](https://github.com/mylittleblover/JukeKart-Android/issues)
