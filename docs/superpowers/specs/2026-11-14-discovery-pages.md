# 首页、媒体与曲目详情续作规格

用户已明确授权：互动页修复后，直接按交接清单和设计稿继续剩余页面；不重复审批。完整行为基线仍为 `/workspace/mkw-handoff/MKW_Player_Codex_交接包_2026-11-11/01_给Codex的指令与规范/02_已确定需求与禁止反悔.md` 和方案 A 修订版。此文件限定下一独立子项目，不取消普通预设、队列、导入恢复等后续工作。

## 页面与数据

- 最终四个一级入口：首页 / 媒体 / 地图 / 播放列表。设置为全局入口，互动控制台由赛道详情或正在播放入口进入。
- 首页每日推荐仅放顶部大封面轮播；10首、手机本地日期零点更新、日内顺序固定；赛道与自由驾驶约各半。只推荐可用且允许显示的内容；候选不足时不捏造条目。
- 每日推荐点击进入详情，不直接抢占当前演奏。下方仅一条真实未完成会话；没有可恢复记录则不显示“已保存”之类文案。收藏使用稳定音乐身份并持久化。
- 媒体六分类：大奖赛 / 生存赛 / VS赛 / 自由驾驶音乐 / 其他配乐 / 短音效。支持实际搜索。大奖赛/生存赛复用已核对官方顺序；无真实元数据/音源的分类显示明确空状态，不用地图近邻或原始归档号杜撰音乐身份、来源版本或分类。
- 赛道详情上下两张全宽卡：普通播放与互动播放。普通播放默认选择完整组曲；不能把仍会无限等待的互动 Pre 当作普通完整组曲。内置预设的具体循环与默认结束分支目前已向用户异步询问，回答到达前不冒充已有已验证的比赛编排。
- 互动入口保留已验证 Native 控制和取消、区域/版本开关；不能用 UI 计时改写采样衔接。直接起始阶段的选择须有真实声源及明确启动 API 后开放，不能拿跨阶段任意跳转代替。
- 播放列表入口四个纵向分区：普通列表 / 我的路线各先5条，更多时查看全部；官方 GP 与生存赛全量展示。普通列表允许重复音乐条目；官方路线仍只读。自定义连线继续等待用户的有向表，不开放猜测路线。

## 视觉与运行约束

- 白底轻量 Material 3 方案 A；当前已接入 MkwTheme、原图地图和 StageArt。地图截图封面全部为占位；正式赛道风景图及其他音乐具体封面由用户后续提供。
- 所有新字符串支持 zh-Hans / zh-Hant / en / ja；语言与展示名不进入音乐、路线、列表或导航身份。
- 紧凑窗口底部导航，足够宽或矮横屏按实际空间采用侧栏/导航栏适配；触摸目标至少48dp。文字可换行，内容可滚动，不重现无限高度嵌套滚动。
- 页面切换、语言更改、旋转与浏览详情不停止或重新初始化音频；主动开始其他演奏才替换会话。
- `minSdk=26`、`compileSdk=35`、`targetSdk=35`，沿用现有 Compose/Material3 和 Native 引擎，不新增无必要依赖。
- 保留 v1 mkwpack / trackKey 兼容；UI逻辑身份与声源内容摘要分开。音频、APK、预览WAV及mkwpack不进入Git；不推送远程仓库。

## 本子项目之外但必须继续的工作

预设编排与完整组曲、普通线性播放器及冻结队列、完整会话恢复、后台原子解码导入/检查点恢复、真实 Jukebox 候选池、官方路线音频编排。其可用性不能仅靠静态页面或这里的目录模型宣布完成；分成后续独立执行计划，继续执行，不在页面完成后自动停工。
