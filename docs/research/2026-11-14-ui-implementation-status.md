## 后续数据边界

正式风景封面、其他音乐封面与目录、完整组曲和其他预设总内容、自定义赛道有向道路表由用户后续提供。不要用虚构的预设、近邻道路或来源游戏目录填满页面。

普通有限编排、冻结队列与完整持久播放会话恢复仍是独立功能工作，不能把当前的可编辑曲目列表称为已具备这些功能。互动原生时间轴与停止状态不应由 UI 动画计时替代。

## 当前验证

最新统一 JVM 测试 1251 项、0 失败、10 项条件跳过，APK 与 instrumentation APK 构建通过；随后仅调整按钮同排等高和大字体换行布局。21 条真实生产图 Bridge 起播原生渲染全部核对通过（采样同步或零点立即切入的声源偏移；0 欠载、0 解码失败、0 削波）。预览工具修正同一采样时刻指令按原始顺序执行，避免按目标编号错误重排。

独立代码复核发现并修复：首次未布局地图的路线适配；直接 Bridge 必经自动衔接不可取消。Rainbow Area2 的推进直接复用最近可达 Outro，随后沿既有自动链路继续；不修改退出点或混音时序。

安装后截图验收仍未完成：本次模拟器 Android 系统在启动应用前因网络栈断开而循环崩溃，不能据此宣称任何真机视觉验收通过。实际手机仍需核对布局、迷你播放器开关闪动和多 Pattern 流畅度。
